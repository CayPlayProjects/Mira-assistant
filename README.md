## Установка

**Требуется:** Python 3.10+, Windows

### 1. Зависимости

```bash
pip install -r requirements.txt
```

> Если ошибка с PyAudio:
> ```bash
> pip install pipwin
> pipwin install pyaudio
> ```

### 2. Настройка ИИ (любой провайдер)

#### OpenRouter (облако)
1. Регистрация на [openrouter.ai](https://openrouter.ai)
2. Получите API-ключ
3. В MIRA: **Настройки → провайдер: openrouter → вставьте ключ**

#### Polza (облако)
1. Регистрация на [polza.ai](https://polza.ai)
2. Получите API-ключ
3. В MIRA: **Настройки → провайдер: polza → вставьте ключ и URL**

#### Router (облако)
1. Регистрация на [router.ai](https://router.ai)
2. Получите API-ключ
3. В MIRA: **Настройки → провайдер: router → вставьте ключ и URL**

#### Custom (любой OpenAI-совместимый)
1. В MIRA: **Настройки → провайдер: custom**
2. Укажите Base URL, API Key, Model Name

#### Ollama (локально)
1. Установите Ollama: [ollama.com/download](https://ollama.com/download)
2. Скачайте модель: `ollama pull qwen3:1.7b`
3. В MIRA: **Настройки → провайдер: ollama**

### 3. Запуск

```bash
python mira.py
```

## Конфигурация

Файл `mira_config.json` создаётся автоматически при первом запуске.

### Провайдеры ИИ

```json
{
    "ai_provider": "openrouter",
    "openrouter": {
        "api_key": "sk-or-...",
        "base_url": "https://openrouter.ai/api/v1/chat/completions",
        "model": "google/gemini-2.0-flash-001"
    },
    "polza": {
        "api_key": "...",
        "base_url": "https://api.polza.ai/v1/chat/completions",
        "model": "gpt-4o"
    },
    "router": {
        "api_key": "...",
        "base_url": "https://api.router.ai/v1/chat/completions",
        "model": "gpt-4o"
    },
    "custom": {
        "api_key": "...",
        "base_url": "https://your-api.com/v1/chat/completions",
        "model": "your-model"
    },
    "ollama": {
        "base_url": "http://localhost:11434",
        "model": "qwen3:1.7b"
    }
}
```

### Псевдонимы

```json
"aliases": {
```

## FAQ

**Q: Как сменить провайдера ИИ?**
A: **Настройки** → выберите провайдера из списка → вставьте API Key, Base URL и Model.

**Q: Не работает голос.**
A: Проверьте микрофон в настройках Windows. Нажмите 🎤 и говорите.

**Q: Как добавить приложение?**
A: Откройте `mira_config.json` → `"aliases"` → добавьте `"название": "путь.exe"`.

**Q: Как свернуть в трей?**
A: Нажмите **✕** — MIRA свернётся в трей. Двойной клик по иконке — восстановление.
